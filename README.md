# Bitácora Espacial

Aplicación web desarrollada en React y Vite que permite explorar y buscar noticias espaciales recientes utilizando la Spaceflight News API.

## Tecnologías utilizadas
* React (Vite)
* CSS moderno (Capas, Variables, Container Queries y Subgrid)
* Spaceflight News API

## Cómo correr el proyecto localmente

1. Clona este repositorio o descarga los archivos.
2. Instala las dependencias ejecutando en la terminal:
   ```bash
   npm install
Crea un archivo .env en la raíz del proyecto y define tu variable de entorno:

Fragmento de código
VITE_API_URL=[https://api.spaceflightnewsapi.net/v4](https://api.spaceflightnewsapi.net/v4)
Inicia el servidor de desarrollo:

Bash
npm run dev
Abre la URL que aparece en tu terminal (usualmente http://localhost:5173) en el navegador.
